🚀 Getting Started

1. Clone the repository

git clone https://github.com/ShivakshChaudhary/Motorola-Clone.git

2. Enter the project

cd Motorola-Clone

3. Run the website

Open index.html in your browser.

For development, I recommend using VS Code + Live Server.
