**Motorola Clone 📱**

A responsive Motorola clone built with HTML and CSS, inspired by the design and layout of the official Motorola website.

This project was created as a frontend practice project to improve my skills in HTML, CSS, responsive design, layouts, positioning, and modern UI development.

**«⚠️ Disclaimer:** This is a fan-made educational project and is not affiliated with, endorsed by, or officially connected to Motorola.»

**✨ Features**

- 🎨 Motorola-inspired homepage design
- 📱 Responsive layout
- 🖼️ Product showcase sections
- 🧭 Navigation/header section
- 🔘 Buttons and call-to-action sections
- 📐 CSS-based layouts and positioning
- 💻 Desktop and mobile-friendly design
- ⚡ Lightweight — built without frameworks

**🛠️ Technologies Used**

- HTML5
- CSS3

**🚀 Getting Started**

1. Clone the repository

git clone https://github.com/ShivakshChaudhary/Motorola-Clone.git

2. Open the project

Navigate into the project folder:

cd Motorola-Clone

3. Run the website

Simply open "index.html" in your browser.

For the best development experience, you can use VS Code with the Live Server extension.

**🎯 Purpose**

The goal of this project was to practice recreating a real-world website interface from scratch.

Through this project, I practiced:

- HTML page structure
- CSS Flexbox
- CSS positioning
- Responsive layouts
- Image placement and sizing
- Navigation design
- Buttons and UI components
- Spacing and alignment
- Creating sections that adapt to different screen sizes
